Lee, comparte y organízate

Una editorial anarquista no existe para vender libros. Existe para hacer propaganda: un acto político para que las ideas anarquistas circulen, se discutan y se propaguen.

El conocimiento no se vende. Todo lo que publicamos se puede leer, descargar y copiar sin pagar. Quien compra un cuadernillo impreso no compra el texto: sostiene la editorial, el papel, la tinta y la próxima reimpresión.

Publicamos historia, teoría y experiencias de acción anarquista, porque una lucha que olvida su memoria repite sus derrotas, y una que no la analiza no aprende de ellas. Recuperamos lo que fue ocultado y lo que se dio por perdido, y traducimos lo que no llegó.

Publicamos para que circule, se subraye, se comparta y se discuta. Un texto que no se puede copiar no se puede propagar.

No tenemos jefes ni pedimos permiso para reeditar. Si algo de lo que hacemos te sirve, tómalo: reimprímelo, tradúcelo, repártelo.

¡Colectivicemos las ideas!
